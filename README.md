# AUES — обновления для iPhone

Готовые unsigned IPA неофициального клиента АУЭС. Скачайте последнюю версию в [Releases](https://github.com/Mi-Yomi/AUES-Releases/releases/latest), подпишите своим сертификатом и установите поверх приложения с тем же Bundle ID.

Начиная с 0.3.0 приложение предлагает новые версии и скачивает IPA из этого канала. Автоматическая установка unsigned IPA не поддерживается.

Репозиторий содержит только описание и файлы релизов. Исходники, учётные данные и данные студентов здесь не публикуются.

AUES не является официальным приложением университета или разработчиков Platonus. Баннер РИТМ предоставлен владельцем проекта; права на изображение сохраняются за его правообладателем.
